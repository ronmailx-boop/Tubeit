# Tubeit

**Tubeit — כתוביות עברית אוטומטיות ליוטיוב**

אפליקציית ווב פשוטה: מדביקים קישור לסרטון יוטיוב, והסרטון מתנגן עם כתוביות שמתורגמות אוטומטית לעברית — בלי קשר לשפת המקור של הסרטון, ובלי צורך לבחור ידנית "תרגום אוטומטי" בתפריט הכתוביות של יוטיוב בכל סרטון מחדש.

🔗 **האפליקציה החיה:** https://ronmailx-boop.github.io/Tubeit/

## מה זה עושה

1. מדביקים קישור יוטיוב (כל פורמט — `youtube.com/watch`, `youtu.be`, `shorts`, או אפילו מזהה הסרטון בלבד) ולוחצים "טען".
2. הסרטון נטען מוטמע בתוך העמוד, והכתוביות מופעלות אוטומטית ומתורגמות לעברית — גם אם לסרטון אין כתובית עברית מקורית, וגם אם שפת הדיבור בסרטון היא לא אנגלית.
3. התרגום נאכף באופן מתמיד למשך כל הצפייה — אם משהו משנה את שפת הכתובית (כולל שינוי ידני), האפליקציה מחזירה אותה לעברית תוך כמה שניות.
4. אפשר לשלוט בגודל הכתובית על המסך עם סליידר ייעודי.

## תכונות

- **תרגום אוטומטי לעברית שתמיד דולק** — לא תלוי בשפת המקור של הסרטון.
- **אכיפה מתמדת** — הכתובית נשארת בעברית לאורך כל הצפייה, לא רק בתחילת הסרטון.
- **שליטה בגודל הכתובית** — סליידר עם מספר רמות, מ"קטן מאוד" ועד "מקסימלי".
- **התקנה כאפליקציה (PWA)** — בכרום באנדרואיד אפשר להתקין את Tubeit כאפליקציה עצמאית עם אייקון משלה.
- **שיתוף ישיר מיוטיוב** — אחרי ההתקנה, Tubeit מופיע בתפריט השיתוף של אנדרואיד. שיתוף סרטון מאפליקציית יוטיוב ובחירה ב-Tubeit פותחים את הסרטון מתורגם ישירות, בלי להעתיק-להדביק קישור.

## מגבלות ידועות

- אם לסרטון הספציפי אין שום כתובית זמינה ביוטיוב (לא אוטומטית ולא ידנית — למשל כי המעלה כיבה את זה), אין ממה לתרגם. זו מגבלה של יוטיוב עצמו ולא של האפליקציה.
- מיקום הכתובית על המסך ואפשרות לגרור אותה למקום חופשי אינם נתמכים — הכתוביות מוצגות ומעוצבות על ידי נגן יוטיוב (iframe חוצה-מקור), ואין לאפליקציה גישה לשנות את המיקום שלהן.

## טכני

Tubeit הוא קובץ HTML סטטי יחיד (`index.html`), ללא שרת אחורי, המשתמש ב-[YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference) הרשמי כדי להטמיע את הסרטון ולאכוף את מודול הכתוביות. הוא מתארח בחינם על GitHub Pages.
