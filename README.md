# Tubeit

**אפליקציית אנדרואיד אמיתית להיסטוריית קליפבורד**

אפליקציית אנדרואיד נייטיבית (Kotlin), מבוססת על עיצוב וריאציה 4 ("כרטיסיות") מתוך אב-הטיפוס המקורי, שמציגה היסטוריה של פריטים שהועתקו ללוח (קליפבורד) — לגמרי אופליין.

📲 **דף האפליקציה:** https://ronmailx-boop.github.io/Tubeit/ — משם יש קישור ישיר להורדת קובץ ה-APK.

## איך זה עובד

- כל פעם שפותחים את האפליקציה (או חוזרים אליה), היא בודקת מה נמצא כרגע בלוח, ואם זה שונה מהפריט האחרון שנשמר — מוסיפה אותו להיסטוריה, עם זיהוי אוטומטי של הסוג (קישור / טלפון / אימייל / טקסט כללי).
- **למה רק בפתיחה, ולא ברקע כל הזמן?** החל מאנדרואיד 10, המערכת חוסמת מאפליקציות לקרוא את הלוח כשהן לא בקדמת המסך — מגבלת פרטיות של המערכת עצמה, לא של האפליקציה. לכן זו הדרך האוטומטית ביותר האפשרית בלי להפוך לתוכנת מקלדת מלאה או לדרוש הרשאות רגישות במיוחד (Accessibility Service).
- פריטים נשמרים **7 ימים** ואז נמחקים אוטומטית.
- כפתור "העתק" מעתיק בפועל בחזרה ללוח; כפתור "✕" מסיר פריט מההיסטוריה.
- לחיצה על כרטיסייה פותחת אותה בגודל מלא (שימושי לטקסטים ארוכים שנחתכים בתצוגת הרשת) — עם כפתורי העתק/מחק גם שם. פריטים מסוג קישור מוצגים כקישור לחיץ (פותח בדפדפן), ועדיין ניתנים להעתקה כטקסט רגיל.

## מעתיקים כמה דברים ברצף באפליקציות אחרות?

מגבלת אנדרואיד 10 שהוזכרה למעלה חדה יותר ממה שנשמע: היא לא רק חוסמת קריאה ברקע — היא גם אומרת שאם מעתיקים כמה פריטים שונים באפליקציות אחרות ופותחים את Tubeit רק בסוף, האפליקציה יכולה לראות **רק את ההעתקה האחרונה**. הקודמות פשוט לא נגישות לשום אפליקציה חוץ מזו שהעתיקה אותן — אין דרך "לתפוס" אותן בדיעבד.

הפתרון המעשי: **אריח בהתראות המהירות (Quick Settings)** ו/או **קיצור דרך בלחיצה ארוכה על האייקון** — שניהם מפעילים מסך שקוף שנפתח, תופס את מה שבלוח, נותן פידבק קצר (Toast) ונסגר מיד, כך שאפשר "לתפוס" כל העתקה בלי לעבור למסך המלא של האפליקציה.

## אופליין לגמרי

לאפליקציה **אין הרשאת אינטרנט בכלל** — כל הנתונים נשמרים מקומית על המכשיר בלבד (SharedPreferences), שום דבר לא נשלח לשום מקום.

## דרישות מערכת

- **מותאם ל:** Android 16 (targetSdk 36)
- **מינימום:** Android 8.0 / API 26 — טווח שמכסה את רוב המכשירים הפעילים בלי צורך בקוד תאימות לאחור מיותר.

## התקנה

מכיוון שזו לא אפליקציה מ-Google Play, בפעם הראשונה כרום יבקש לאשר "התקנת אפליקציות ממקורות לא ידועים" — צריך לאשר כדי להתקין.

## איך זה נבנה

הפרויקט הוא אפליקציית Kotlin/Gradle רגילה תחת `android/`. ה-APK עצמו **לא נבנה בסביבת הפיתוח** (אין שם גישה ל-Android SDK) — הבנייה קורית אוטומטית דרך GitHub Actions (‏`.github/workflows/build-apk.yml`‏) בכל פעם שיש שינוי בקוד, והקובץ המובנה מתפרסם אוטומטית כ-GitHub Release בשם `latest`, זמין תמיד בכתובת הקבועה:
https://github.com/ronmailx-boop/Tubeit/releases/latest/download/tubeit.apk

חתימת ה-APK מבוססת על מפתח (`android/keystore/tubeit.keystore`) שנוצר ונשמר בריפו כדי שכל גרסה תיחתם באופן זהה — כך שאפשר להתקין עדכון מעל ההתקנה הקיימת בלי להסיר אותה קודם. זהו מפתח אישי להתקנה עצמית בלבד, לא מיועד להפצה ב-Google Play.

## הוריאציות המקוריות

חמשת עיצובי אב-הטיפוס המקוריים (רשימה פשוטה, לפי קטגוריה, ציר זמן, כרטיסיות, מיקוד בחיפוש) עדיין נגישים תחת `variations/`, לעיון ולהשוואה.
