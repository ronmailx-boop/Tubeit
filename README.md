# Tubeit

**אב-טיפוס: היסטוריית קליפבורד — 5 עיצובים שונים**

אב-טיפוס עיצובי (לא אפליקציה מחוברת בפועל) שמדמה כיצד תיראה אפליקציה שמציגה את היסטוריית הפריטים שהועתקו ללוח (קליפבורד), עם 5 גישות שונות לעיצוב ולחוויית המשתמש.

🔗 **תצוגה חיה:** https://ronmailx-boop.github.io/Tubeit/

## למה נתוני דוגמה בלבד

דפדפן אינטרנט לא יכול לעקוב אוטומטית וברקע אחרי כל מה שמעתיקים בטלפון — מטעמי פרטיות, גישה ללוח מתאפשרת רק ברגע שהמשתמש מבצע פעולה מפורשת בתוך הדף (למשל לחיצה על כפתור). מעקב אוטומטי אחרי כל העתקה בכל הטלפון דורש אפליקציית אנדרואיד נייטיבית — פרויקט שונה ומורכב יותר. לכן זהו תרגיל עיצוב וחוויית משתמש עם נתוני דוגמה, לא חיבור אמיתי ללוח (אם כי כפתור ה"העתק" בכל וריאציה כן מעתיק בפועל ללוח, כי זו פעולה שדפדפן כן מאפשר).

## הוריאציות

1. **רשימה פשוטה** — רשימה כרונולוגית מינימלית.
2. **לפי קטגוריה** — קיבוץ לפי סוג תוכן (קישורים / טלפונים / אימיילים / כתובות / קוד / טקסט) עם סינון.
3. **ציר זמן** — תצוגת ציר זמן אנכי, מקובץ לפי יום.
4. **כרטיסיות** — רשת כרטיסיות ויזואלית.
5. **מיקוד בחיפוש** — שורות צפופות, חיפוש מהיר, ואפשרות לנעוץ פריטים חשובים.

## זיכרון היסטוריה

ברירת המחדל שנבחרה היא **7 ימים** — טווח סביר לכלי מסוג זה: מספיק ארוך כדי להיות שימושי, מספיק קצר כדי לא להצטבר לעומס. נתוני הדוגמה בכל וריאציה פרוסים על פני החלון הזה.
